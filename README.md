# متابعة يوتيوب لـ«رِحلة»

كل جمعة يقرأ آخر فيديوهات القنوات اللي تختارها، ويحفظ اللي تذكر وجهة من الكتالوج في `data/youtube-candidates.json`.

## التشغيل لأول مرة (10 دقائق)

1. في GitHub: **New repository**، سمّه `rihla-youtube-watch`، واختر **Private**.
2. ارفع محتوى هذا المجلد كما هو، ومعه مجلد `.github` (في الماك اضغط Cmd+Shift+. عشان يطلع لك المجلد المخفي).
3. عدّل `channels.json` وحط القنوات بأسمائها وأرقام تعريفها اللي تبدأ بـ`UC`.
4. من **Settings ← Actions ← General**، اختر **Read and write permissions** تحت Workflow permissions.
5. من تبويب **Actions** افتح «متابعة يوتيوب لرحلة» واضغط **Run workflow** عشان تجربه.
6. بعد دقيقة يطلع لك `data/youtube-candidates.json`.

## المراجعة

- كل فيديو جديد يكون `status: "مرشح للمراجعة"`. غيّره إلى `"ينفع"` أو `"ما ينفع"`، والسكربت ما يرجع يكتب عليه.
- اللي «ينفع» أعطه Claude، يطلّع منه الأماكن ويضيفها للوجهة.
- «رِحلة» تقرأ الملف وتعرض فيديوهات «ينفع» في «كلام الناس» بمشغّل يوتيوب المدمج، مع اسم القناة.

## إضافة وجهة

أضفها في `destinations.json` مع كلماتها بالعربي والإنجليزي.

## ملاحظات

- RSS يجيب آخر 15 فيديو لكل قناة بس. عشان كذا يشتغل كل أسبوع.
- ما ينزّل فيديوهات ولا ينسخ محتوى. يحفظ العنوان والرابط والوصف المختصر.
