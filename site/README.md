# رِحلة — مستشارك الشخصي للسفر

موقع عربي RTL يعمل بـ React / TypeScript / Vinext على Cloudflare Workers، مع قاعدة D1 وحفظ خاص حسب هوية المستخدم التي توفرها منصة Sites.

هذه نسخة مصدر الإصدار **47** من رِحلة، من الالتزام `b9bcaad853e85ab4c84213fd6208258251cd64d9`. تتضمن التطبيق والخادم والبيانات المضمّنة والاختبارات وترحيلات قاعدة البيانات.

## التشغيل والبناء محليًا

استخدم **Node.js 24** و**pnpm 11.25.0**. نفّذ الأوامر من مجلد `Rihla` بعد فك الضغط:

```bash
pnpm install --frozen-lockfile
node --test tests/*.test.mjs
pnpm exec tsc --noEmit --incremental false
pnpm build
```

البناء يخرج ملفات الواجهة في `dist/client/` وملفات الخادم في `dist/server/`. لاختبار التخزين محليًا، جهّز قاعدة D1 **مرة واحدة** بعد البناء. الأوامر الآتية تعمل في Bash أو PowerShell:

```bash
pnpm exec wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_absent_tempest.sql
pnpm exec wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_third_wallow.sql
pnpm exec wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_flippant_cobalt_man.sql
pnpm exec wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0003_faithful_epoch.sql
pnpm dev
```

افتح الرابط المحلي الذي يطبعه الخادم (عادةً `http://localhost:5173`). لتجربة الحفظ، افتح `/signin-with-chatgpt?return_to=/` على نفس المضيف المحلي. هذا دخول تجريبي ولا يتصل بحساب ChatGPT أو بقاعدة الإنتاج.

## النقل إلى GitHub Pages

تقدر ترفع محتويات مجلد `Rihla` إلى مستودع GitHub للمصدر. [GitHub Pages يستضيف ملفات ثابتة](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site). بناء رِحلة الحالي يُشغّل واجهة مع Worker، ورفع `dist/client` وحده لا يشغّل التطبيق.

- **للنسخة الكاملة:** شغّلها على استضافة تدعم Cloudflare Workers، واربط قاعدة D1 باسم `DB` وطبّق ملفات `drizzle/`. خارج Sites يلزم تهيئة مصادقة إنتاج موثوقة قبل فتح التطبيق للزوار. حاليًا يقرأ `app/chatgpt-auth.ts` هوية المستخدم من بوابة Sites. اضبط بديل المصادقة على الخادم، ولا تعتمد على ترويسات الهوية التي يرسلها الزائر مباشرة.
- **إذا تبي واجهة على Pages:** جهّز مدخل HTML ثابتًا للواجهة واضبط مسارات الأصول إذا كانت تحت `/اسم-المستودع/`. اربط ما يحتاج خادمًا بعنوان API منفصل مع مصادقة وCORS مناسبين، أو عطّل وظائف الخادم للنسخة الثابتة. بعد توليد مجلد فيه `index.html`، انشر ناتج الواجهة عبر [GitHub Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). هذا الأرشيف يحتوي مصدر التطبيق الأصلي، وتجهيز بناء Pages الثابت خطوة منفصلة.

تشمل الوظائف المعتمدة على الخادم تسجيل الدخول، والمزامنة، وحفظ الخطط والملاحظات، وبعض أدوات البحث والطقس. انقل الرحلات الشخصية على حدة بتصدير JSON من «الإعدادات» في الموقع الحالي، واحتفظ به خارج المستودع العام. راجع أيضًا `THIRD_PARTY_NOTICES.md` وملفات التراخيص قبل إعادة النشر.

## أين الملفات؟

| المسار | المحتوى |
| --- | --- |
| `app/` و`components/` و`hooks/` | الواجهة ومسارات API |

الأرشيف يحتوي بيانات الموقع المضمّنة في المستودع. الرحلات المحفوظة في الحساب وقاعدة الإنتاج والأسرار والتبعيات المُثبّتة ونواتج البناء منفصلة عنه.

## البيانات وحدودها
## تحديث مساحة التخطيط
- بطاقات أنشطة متعددة في اليوم، مع سحب وترتيب بالأسهم ونقل بين الأيام، ووقت ومدة وأولوية ورابط وملاحظات وتكلفة للمجموعة.
- قائمة أفكار مستقلة لكل وجهة؛ نقل الفكرة إلى يوم يحافظ على تفاصيلها.
- تنبيهات تداخل الأوقات وتجاوز ٨ ساعات من الأنشطة؛ لا تحسب زمن الطريق أو ساعات العمل.
- رسوم إضافية متوقعة تدخل في التقدير مرة واحدة، وسجل مصروفات فعلي منفصل حتى لا تتكرر المبالغ.
- طباعة الخطة وحفظ PDF عبر نافذة الطباعة، وتصدير ICS بأحداث يوم كامل وأوقات الأنشطة المحلية في الوصف.
- ترقية تلقائية لخطط الإصدار السابق مع الحفاظ على النصوص؛ العميل القديم يُمنع من الكتابة فوق الحقول الجديدة. لا يتطلب تغيير بنية D1.
- مكونات الترتيب من dnd-kit بترخيص MIT؛ راجع THIRD_PARTY_NOTICES.md و licenses/dnd-kit-MIT.txt.
- اختبارات منطق التخطيط: `node --test tests/planning.test.mjs` (Node 24 يدعم TypeScript مباشرة).

## مصادر المحتوى وحدوده
- ست وجهات: كيوتو، إسطنبول، لشبونة، سنغافورة، دبي، مراكش.
- روابط رسمية وتاريخ مراجعة 2026-09-24 في lib/travel.ts.
- التقويم يغطي عطلات اليابان الوطنية لعامي ٢٠٢٦ و٢٠٢٧ ومجموعة من عطلات سنغافورة؛ نافذة خريف كيوتو تقريبية.
- لا يوجد ربط بأسعار الطيران أو الفنادق أو مدة الوصول، ولا تحويل عملات أو خدمة حجز. الطقس الرسمي مرتبط للشبونة وسنغافورة فقط.
- التأشيرات: إحالة إلى الجهة الرسمية مع الجنسية المدخلة، دون إصدار حكم آلي بالأهلية.
- التكلفة نطاقات يكتبها المستخدم، لا بيانات سوق أو عروض حجز. السكن يحسب بعدد الليالي والغرف، والبنود اليومية بعدد المسافرين والأيام.
- مُنشئ الخطة خوارزمية تنظيمية محلية حسب الاهتمامات والوتيرة؛ ليس محادثة ذكاء اصطناعي أو ضمانًا لملاءمة الميزانية.
- الحفظ في D1 وليس في التخزين المحلي للمتصفح. جميع طلبات القراءة والكتابة تربط السجل بمعرف المستخدم على الخادم. تعارض تعديلات الأجهزة يُظهر رسالة بدل الكتابة الصامتة فوق نسخة أخرى.

## التكاملات المستقبلية
## التوصيات والطقس الرسمي
الاقتراحات تشرح الاهتمامات المطابقة والتحفظات الموسمية والمناسبات ونقص البيانات. الترتيب حسب عدد الاهتمامات المتطابقة فقط؛ لا يوجد تقييم رقمي لمدى دقة التوصية ولا ادعاء بأن التكلفة أو التأشيرة أو زمن الوصول معروف.

المسار `/api/weather` يتطلب تسجيل الدخول ويستدعي نقطتين ثابتتين من IPMA للشبونة و NEA / MSS عبر data.gov.sg لسنغافورة. لا يرسل بيانات الرحلة أو المستخدم إلى المزود، ويتحقق من بنية الرد وحداثته. ذاكرة مؤقتة لمدة ١٥ دقيقة، ومهلة ٨ ثوان، وفشل واضح دون اختلاق توقع بديل. يعرض أيام الرحلة المتقاطعة فقط مع وقت جلب البيانات ووقت التحديث كما ورد. التغطية تقارب خمسة أيام للشبونة وأربعة لسنغافورة حسب استجابة المصدر؛ بقية الوجهات والتواريخ غير المتاحة معلنة بوضوح.

مصادر الربط: https://api.ipma.pt/ و https://data.gov.sg/datasets/d_f131f6e343bf8168e4057a04c4326a0a/view . العطلات اليابانية الوطنية موثقة لعامي ٢٠٢٦–٢٠٢٧ من مجلس الوزراء؛ سنغافورة مجموعة جزئية، وبقية البلدان غير مغطاة. لا يتم تكرار عطلات متغيرة تلقائيًا.

التحقق: `node --test tests/*.test.mjs` و TypeScript والبناء. اختبارات تشمل عبور السنة والشهر الكبيس، تطابق البلد، نقص الميزانية، ورفض توقعات قديمة أو غير صالحة.

## الخدمات غير المرتبطة
## خريطة الأنشطة
تبويب «الخريطة» يعرض أنشطة الوجهة حسب اليوم أو كل الأيام. اختر نشاطًا، ثم نقطة بالخريطة أو مركز العرض أو إحداثيات صحيحة، واضغط «احفظ موقع النشاط». لا تُخمن إحداثيات المعالم من أسمائها؛ مراكز المدن التقريبية لتهيئة العرض فقط. لا تطلب الخريطة موقع الجهاز.

المواقع تحفظ ضمن النشاط في D1 وتنتقل معه بين الأيام والأفكار، وتدخل في JSON والتقويم والطباعة. ترقية البيانات إلى schemaVersion 3 تحفظ حقول الإصدار السابق، وترفض كتابة العملاء الأقدم لحماية الإحداثيات. لا تتطلب تغيير بنية قاعدة البيانات.

حساب القرب بمسافات دائرة عظمى مباشرة على كرة أرضية؛ لا يمثل طريقًا أو وقت تنقل. الوصلات التي تفتقد موقعًا لا تدخل المجموع. اقتراح الترتيب يبقي النشاط الأول ويختار الأقرب تباعًا، ويحتاج مواقع كاملة وأنشطة دون أوقات ثابتة. يطبق المستخدم المعاينة صراحة؛ ليس حلًا أمثل مضمونًا ولا يراعي ساعات العمل.

Leaflet 1.9.4 بترخيص BSD-2-Clause؛ البلاطات من OpenStreetMap مع إسناد ظاهر. لا يوجد تنزيل بلاطات دون اتصال أو جلب جماعي. البحث والمسارات في Google Maps روابط خارجية فقط؛ لا يوجد بحث جغرافي آلي أو استرجاع أوقات المسار داخل الموقع. راجع THIRD_PARTY_NOTICES.md.

## التكاملات اللاحقة
lib/providers.ts يحدد عقود الخدمات غير المرتبطة. ينبغي تنفيذ مزود خادم موثوق يعيد المصدر ووقت التحقق والعملة والافتراضات، مع التمييز بين unavailable وlive وestimate. لا ترسل الجنسية أو تفاصيل الرحلة إلى مزود دون حاجة. لا تضع مفاتيح الخدمات في الواجهة. العطلات المؤكدة تُضاف فقط بعد مراجعة الجهة الرسمية، ولا تُكرر التواريخ المتغيرة تلقائيًا كل عام.

## خريطة العالم
تبويب مستقل يشمل 250 دولة وإقليمًا، وحدودًا مبسطة مع نقاط بديلة للدول الصغيرة. خريطة بلا مفتاح خدمة، وبياناتها الجغرافية مستضافة مع الموقع. حفظ زرتها وأبي أزورها والشهر والملاحظات ضمن الحساب (schemaVersion 4)، مع رفض كتابة الإصدارات الأقدم لحماية البيانات. 10 أدلة بداية، وسجلات تأشيرات محدودة موثقة للسعودي؛ المجهول يظهر صراحة. مصدر كل معلومة وتاريخ مراجعتها موضحان، ولا تمثل التأشيرة تصريح سفر من السعودية. مؤشرات الموسم ليست توقعات ولا أسعارًا مضمونة.
صفحة أسعار السفر تقارن متطلبات Duffel وBooking.com وSkyscanner. لم يُربط مزوّد أو يُفعّل اشتراك. عقود السكن والطيران في lib/providers.ts تعيد عدم التوفر حتى تنفيذ التكامل. تقويم العطلات وتوقعات الطقس السابقان ما زالا محدودي التغطية حسب الوجهة.

### بيانات الدول المرفقة

ملف `lib/country-package.json` هو لقطة `countries/all.json` من حزمة تطوير رِحلة. للتحديث شغّل مولّد الحزمة وفق `countries/README.md` ثم استبدل اللقطة وشغّل `node --test tests/country-package.test.mjs`. راجع مؤشرات التأشيرة لدى الجهات الرسمية وحدّث تاريخ المراجعات في `lib/country-package.ts` عند إعادة التحقق. بيانات المناخ الشهرية تأتي من جدول NASA POWER المستخدم في دليل الدولة.

توسعة الكتالوج تستهلك لقطات `youtube-watch/countries/data/all.json` و`youtube-watch/countries/combos.json` في `lib/country-catalog.json` و`lib/travel-combos.json`. تعرض صفحات الدول أحدث البيانات المرفقة مع المراجعات الرسمية السابقة، وتستخدم اللقطة السابقة للعطلات إذا كان تقويم اللقطة الجديدة خاليًا.

تقرأ رِحلة مرشحي يوتيوب من `data/youtube-candidates.json`. لتحديث لقطة المستودع من ملف تصدير موثوق، شغّل `node scripts/update-youtube-candidates.mjs <ملف-التصدير-أو-رابط-HTTPS>` ثم شغّل اختبارات الكتالوج قبل النشر. أضف `--merge` بعد المصدر عند تحديث بعض المقاطع حتى تبقى بقية السجلات. تتحقق الأداة من البيانات بصيغة المستورد داخل الموقع وتحفظ المدد والخلاصات التي وردت في المصدر. يمكن أيضًا استيراد اللقطة إلى الموقع من الإعدادات.

للملف الأسبوعي من مراقب يوتيوب استخدم `--watcher` لدمج المدد و`tips_ar` بمعرّف المقطع والمحافظة على التقييمات والخلاصات المحلية. يبدأ تحديث الجمعة بملف المراقب الخام، وتكفي نصيحة جديدة أو معدّلة لنشر اللقطة.
